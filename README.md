# ImGui for BlitzMax

BlitzMax bindings for Dear ImGui, with renderer integrations and additional widgets.

## SDL backends

- **SDL3:** platform input, SDL renderer and native SDL GPU backends, including overlays for the corresponding Max2D backends. See the [SDL3 guide and examples](docs/sdl3.md).
- **SDL2:** the existing `ImGui.ImGuiSDL2` and `ImGui.ImGuiSDL2Renderer` modules remain available.

For updating the bundled sources and generated bindings, see the [generation instructions](imgui.mod/imgui_to_bmx/readme.md).
